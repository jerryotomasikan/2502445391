# Added prediction and lineage schemas

Original prediction files: clean_row_index is a zero-based index into the deduplicated (or retained) analyzed frame; quality_true is the transformed ordinal grade; binary_true is 0/1; p_<model> is positive-class probability; pred_<model> in the binary file is 0/1; score_<model> in ordinal files is continuous grade score; pred_<model> in ordinal files is discrete grade. AUC, probabilities, F1 and kappa are dimensionless. MAE is in constructed grade units. Models and grades must be interpreted using the selection lock and target JSON for the same run.

Lineage CSVs: source_row_index is the zero-based data-row index in the hash-matched source CSV excluding its header; analysis_row_index is position after optional subsampling; duplicate_group_id groups exact retained predictor vectors within that analyzed sample (local to the run, not a global cross-source ID); kept is 0/1; clean_row_index is -1 for discarded duplicates or the index used in saved prediction and split files; ordinal_target/binary_target are transformed labels; split is development/test/discarded_duplicate; bin_validation_fold and ord_validation_fold are 0..4 for retained development observations, otherwise -1. Source identity is source_filename in the target JSON plus source SHA256 in data_audit.json. Do not treat clean_row_index as a source-row identifier.

Baseline CSVs: constant_prediction is the within-one-optimal grade selected only on development, with smallest-grade tie-breaking. within_one_correct is 0/1 on that run's holdout; source_row_index links it to the original input CSV. This ordinal constant is different from binary DummyPrior predictions, which remain separately in test_predictions_binary.csv.

NPZ files: split_indices arrays contain clean-row indices; cv_folds arrays contain development-relative positions, to be mapped via development[fold_indices]. All are numeric arrays loadable with allow_pickle=False.

Target JSONs: bin_edges are reconstructed full-precision numeric cutpoints before sparse merging; raw_bin_to_final_grade maps original interval codes to final grade codes. Quantile binning drops duplicate edges; uniform binning uses pandas.cut range adjustment. Intervals are right-closed; the first interval includes the minimum. Native targets have null edges and retain native/merged metadata. binary_threshold is a source-target value; binary_operator is >= for native thresholds or > for the computed full-sample median. Boundaries are reconstructed and checksum-verified, not claimed as originally logged.

Original data audits, split/selection locks, evaluation contexts, metric CSVs and paired-bootstrap summary CSVs are preserved byte-for-byte from supplied evidence. They include historical local file paths that do not need to exist on the verifier's machine. Generation code and individual field schemas are identified in the parent repository; no path-specific code is needed for the new verifier.
